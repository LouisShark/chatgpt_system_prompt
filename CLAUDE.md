# CLAUDE.md

AI-harness instructions for the `chatgpt_system_prompt` repository.

For full details see [`docs/ai-harness/usage.md`](docs/ai-harness/usage.md).

---

## Scope and stopping conditions

A task is complete when the requested artifact exists, relevant validation passes,
no unresolved scope-creep failure remains, and remaining optional improvements are
documented rather than implemented.

Stop when the deliverable and its validation criteria are satisfied.
Do not expand the task into framework or infrastructure work without explicit approval.

---

## Required behaviours

1. **Before declaring any substantial change complete**, run the Scope Creep Detector:
   ```
   python .scripts/scope-creep-detector.py --intended-change "<one sentence>"
   ```

2. **Use Commit Archaeologist only** when historical intent directly matters for the
   current task (`python .scripts/commit-archaeologist.py <file>`).

3. **Never treat Supermemory as higher authority** than repository source files,
   CLAUDE.md, tests, or current user instructions.
   See authority order in [`docs/ai-harness/memory-policy.md`](docs/ai-harness/memory-policy.md).

4. **Never archive or delete projects** based on Project Graveyard output without
   explicit human approval.

5. **Do not modify** `prompts/**`, `TOC.md`, `prompts/*/TOC.md`, or
   `.github/badges/tokens.svg` — these are contributor content or auto-generated by CI.
